Important — how this Admin works: No PIN, no password on this page — it opens directly, and it is not linked anywhere on the store, so customers cannot find it from the website. This is hiding, not real login security: anyone who learns the address can open it, because GitHub Pages has no server to check a password. For a real password login checked on a server, the store needs a backend (ask the assistant about the Vercel/backend option). Changes you make here are saved on this device only. Make It Live — how to publish admin changes

1. In Products, click Export Products JSON and save the file.
2. Send that file to the assistant, or upload it to GitHub yourself: replace script.js — paste the exported products into the DEFAULT_PRODUCTS list at the top of the file — then commit.
3. GitHub Pages rebuilds in a minute or two and every visitor sees the new products.
Order statuses and settings are device-only and do not need publishing — customers are notified on WhatsApp/email at order time.
